# Q4: Trajectory Anomaly / Abnormal Displacement Detection

任务背景：在王者荣耀手游录屏中，先对英雄做逐帧位置跟踪（小地图坐标或屏幕坐标），再判断某一帧位置发生了"非物理"的突然跳跃（位移量远超英雄最大移动速度 × Δt），以推断闪现（Flash）技能被使用。

**检索结论摘要**：没有找到任何直接针对"MOBA 游戏中角色瞬移/闪现检测"的学术论文（**未找到直接相关研究（游戏闪现检测本身）**）。但轨迹异常检测（trajectory anomaly detection）与时间序列点异常检测（point anomaly detection）方向有成熟且高度可迁移的方法论。以下 5 篇均已通过抓取一级来源页面（arXiv abs / CVF openaccess / ACM DOI / OpenReview）核对标题、作者、年份、发表场所。

## Directly related research（可迁移的核心方法研究）

### 1. Learning Regularity in Skeleton Trajectories for Anomaly Detection in Videos
- **Authors**: Romero Morais, Vuong Le, Truyen Tran, Budhaditya Saha, Moussa Mansour, Svetha Venkatesh
- **Year**: 2019
- **Venue / ID**: CVPR 2019（Proceedings of the IEEE/CVF CVPR）；arXiv:1903.03295
- **Verified URL**: [CVF Open Access 页面](https://openaccess.thecvf.com/content_CVPR_2019/html/Morais_Learning_Regularity_in_Skeleton_Trajectories_for_Anomaly_Detection_in_Videos_CVPR_2019_paper.html)（另见 [arXiv:1903.03295](https://arxiv.org/abs/1903.03295)）
- **Task / dataset**: 监控视频中的人体相关异常事件检测。核心思路是不用外观特征，而用动态骨架特征建模"正常运动模式"，并把骨架运动**显式分解为 global body movement（整体位移轨迹）与 local body posture（局部姿态）**，用 Message-Passing Encoder-Decoder Recurrent Network 建模两者的动力学与交互；重构/预测误差大即判为异常。论文页面未指名具体数据集（原文实验为 ShanghaiTech / HR 类监控基准）。
- **Relevance**: **transferable（强）**
- **Migration assessment**: 这篇的"global movement 分支"几乎就是我们需要的东西——它专门学习被跟踪主体质心轨迹的正常动力学，闪现造成的瞬时大位移会在预测/重构误差上形成尖峰。迁移代价在于：它是自监督（只需"正常"轨迹，不需要异常标注），这对我们非常友好；但原模型面向 30fps 人体骨架序列，我方只有 2D 位置序列，实际可只保留其 global 分支（一个轻量 RNN encoder-decoder），单机 CPU/GPU 即可实时跑，工程上完全可行。

### 2. Trajectory Outlier Detection: Algorithms, Taxonomies, Evaluation, and Open Challenges
- **Authors**: Asma Belhadi, Youcef Djenouri, Jerry Chun-Wei Lin, Alberto Cano
- **Year**: 2020
- **Venue / ID**: ACM Transactions on Management Information Systems (TMIS)；DOI 10.1145/3399631
- **Verified URL**: [ACM Digital Library](https://dl.acm.org/doi/10.1145/3399631)（期刊归属另见 [OpenAIRE 记录](https://oamonitor.ireland.openaire.eu/national/search/publication?pid=10.1145/3399631)）
- **Task / dataset**: 综述类文献，系统梳理轨迹异常/离群检测的算法家族（基于距离/密度、基于历史相似性、基于分类与聚类、基于深度学习）、分类体系、评测方法与开放挑战。ACM 页面本身未展示摘要正文，仅确认标题、作者与日期。
- **Relevance**: **adjacent（方法学地图）**
- **Migration assessment**: 不提供可直接调用的模型，但对我们选型有决定性价值：它明确区分"整条轨迹异常"与"轨迹内的点异常/子段异常"，而闪现属于典型的**点异常（point outlier，速度/位移突变）**，据此可以先上最简单的基于运动学阈值 + 密度/距离的 baseline，再决定是否需要深度模型。零算力成本，属于必读的立项参考。

### 3. Anomaly Transformer: Time Series Anomaly Detection with Association Discrepancy
- **Authors**: Jiehui Xu, Haixu Wu, Jianmin Wang, Mingsheng Long
- **Year**: 2022（arXiv 首次提交 2021-10）
- **Venue / ID**: ICLR 2022；arXiv:2110.02642
- **Verified URL**: [OpenReview (ICLR 2022)](https://openreview.net/forum?id=LzQQ89U1qm_)（另见 [arXiv:2110.02642](https://arxiv.org/abs/2110.02642)）
- **Task / dataset**: 无监督时间序列**点异常**检测。提出 Anomaly-Attention 与 Association Discrepancy 判据：异常点难以与整条序列建立非平凡关联，其注意力主要集中在邻近时刻；配合 minimax 训练放大正常/异常可分性。在服务监控、空间与地球探测、水处理三类应用共 6 个无监督基准上达到 SOTA。
- **Relevance**: **transferable（强，但可能过重）**
- **Migration assessment**: 把英雄坐标序列 (x_t, y_t) 或位移量 |Δp_t| 当作多变量时间序列直接喂入即可输出逐时刻异常分数，天然对齐"哪一帧发生了闪现"这一定位需求，且完全无监督、不需要标注闪现帧。缺点是 Transformer 对一段只有几百帧的短序列属于牛刀杀鸡，训练/推理成本和调参代价都明显高于阈值法；建议作为 baseline 打不平时的升级方案，而非首选。

### 4. Trajectory Anomaly Detection with Language Models (LM-TAD)
- **Authors**: Jonathan Mbuya, Dieter Pfoser, Antonios Anastasopoulos
- **Year**: 2024
- **Venue / ID**: arXiv:2409.15366（cs.LG / cs.AI，2024-09-18）
- **Verified URL**: [arXiv:2409.15366](https://arxiv.org/abs/2409.15366)
- **Task / dataset**: 用自回归 causal-attention 语言模型建模轨迹（把轨迹当 token 序列，支持 GPS 坐标 / staypoint / activity type 表示），用 **perplexity 与 surprisal rate** 检测离群并**精确定位轨迹内的异常位置**；支持 user-specific token 以捕捉个体行为差异；通过缓存 attention KV 实现低延迟在线检测。实验数据集：合成数据、Pattern-of-Life (PoL)、Porto taxi。
- **Relevance**: **transferable（中高）**
- **Migration assessment**: 两点对我们特别契合：一是 surprisal rate 给出逐点异常度，正好用于"闪现发生在第几帧"；二是 user token 的思路可迁移为"英雄 token"——不同英雄基础移速/位移技能不同，正常位移分布本就不同。代价是需要把连续坐标离散化成 token 网格，量化粒度会直接影响能否区分闪现（约 8 个身位）与普通位移/技能突进，且需要足够多正常对局轨迹来训练语言模型。

### 5. Online Anomalous Subtrajectory Detection on Road Networks with Deep Reinforcement Learning (RL4OASD)
- **Authors**: Qianru Zhang, Zheng Wang, Cheng Long, Chao Huang, Siu-Ming Yiu, Yiding Liu, Gao Cong, Jieming Shi
- **Year**: 2022
- **Venue / ID**: arXiv:2211.08415（cs.DB / cs.LG，2022-11-12）
- **Verified URL**: [arXiv:2211.08415](https://arxiv.org/abs/2211.08415)
- **Task / dataset**: 在线检测**异常子轨迹**（比整条轨迹更细粒度）。双网络强化学习框架：一网学习路网与轨迹特征，一网基于特征标注异常子段，两者迭代训练且**完全不需要人工标注**；在两个真实数据集上比 SOTA 提升 20–30%，每个新数据点处理耗时 < 0.1 ms。
- **Relevance**: **adjacent / transferable（中）**
- **Migration assessment**: 价值在于两条工程结论：无标注即可训练，以及"逐点在线打标"的推理形态（<0.1 ms/点，录屏逐帧处理完全够用）。但它强依赖路网（road network）结构先验，而 MOBA 地图虽有地形约束却没有等价的路网拓扑，需要用地图可通行区域/最大移速约束替换该模块，属于中等改造量，不建议作为首选实现。

## Conclusion

学术界**没有**"游戏角色闪现/瞬移检测"的直接研究，但该问题在方法论上就是一个标准的**轨迹点异常检测（point outlier in a tracked trajectory）**问题，监控、交通、GPS 三个领域已有大量可直接迁移的成熟方案，且主流方法都是**无监督/自监督**——这意味着我们无需标注闪现帧，只要收集足够多"正常移动"的轨迹即可建模。

实践建议采取阶梯式方案：先用运动学先验做强 baseline（按英雄移速上限设定 |Δp_t| 阈值 + 位移的鲁棒 z-score / 密度离群判据，参考 Belhadi 综述中的 point-outlier 分类），这对"位移量远超物理上限"这种极显著异常大概率已经足够；只有在跟踪噪声、遮挡、镜头缩放导致误报过多时，再升级到 Morais 的 global-movement encoder-decoder（最轻、最贴合）或 Anomaly Transformer / LM-TAD 的逐点异常打分。真正的工程瓶颈不在异常检测算法，而在上游的稳定跟踪与坐标归一化（镜头移动、小地图与主视角坐标系换算、ID 切换），跟踪一旦跳变本身就会产生假闪现。
